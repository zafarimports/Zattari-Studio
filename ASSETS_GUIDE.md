# Asset Files Guide

The following binary image files need to be downloaded from the source repository and added to the `assets/` folder:

## Image Assets

| File | Size | Purpose |
|------|------|---------|
| `hero.webp` | 70 KB | Hero section background image |
| `p1-white-kitchen.webp` | 43 KB | Portfolio case study #1 |
| `p3-bathroom.webp` | 34 KB | Portfolio case study #3 |
| `ba-before.webp` | 75 KB | Before/after comparison - before |
| `ba-after.webp` | 70 KB | Before/after comparison - after |
| `og.png` | 315 KB | Open Graph social sharing image |

## How to Download

You can download these files directly from:
```
https://github.com/zafarimports/grand-river-basements/tree/b11a32611cc19881376db7a3a7a8d0538561514a/zattari-studio/assets/
```

Or clone the repository and copy the `zattari-studio/assets/` folder.

## File Locations

Once downloaded, place them in:
```
Zattari-Studio/
├── assets/
│   ├── hero.webp
│   ├── p1-white-kitchen.webp
│   ├── p3-bathroom.webp
│   ├── ba-before.webp
│   ├── ba-after.webp
│   └── og.png
```

## index.html

The main `index.html` file (63 KB) is too large to display inline but contains:
- Full landing page with animations
- Scroll choreography system
- Canvas particle effects
- Checkout modal with state management
- Email integration configuration
- All inline CSS and JavaScript

To add it, download directly from:
```
https://raw.githubusercontent.com/zafarimports/grand-river-basements/b11a32611cc19881376db7a3a7a8d0538561514a/zattari-studio/index.html
```

And save to `Zattari-Studio/index.html`
