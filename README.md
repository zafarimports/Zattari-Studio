# ZEN ATARI — Growth Systems Studio

Award-style animated landing page + full trial funnel for digital marketing, automation and lead-generation services.

Stack: one hand-built static page. No frameworks, no build step. Open `index.html` — that's the whole site.

## What's inside

```text
index.html        The site: SEO, animations, popups, checkout funnel — all inline
logo.svg          The Signal-Z logo (also inlined in the page + favicon)
assets/           Case-study photography placeholders + og.png placeholder
emails/           6-email trial automation sequence + wiring blueprint
```

## Go live

1. Upload the folder to any static host.
2. Point your domain; update canonical and Open Graph URLs in `index.html`.
3. Replace `CONFIG.LEAD_ENDPOINT` and Stripe links with production endpoints.
